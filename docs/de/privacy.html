Datenschutz

Zuletzt aktualisiert: 11. November 2026

Captionshaper läuft auf deinem Computer. Deine Videos, dein Ton und deine Untertitel verlassen ihn nie.

Was die App mit deinen Dateien macht

Captionshaper liest das geöffnete Video oder Audio, erkennt die Sprache und schreibt Untertitel, alles auf deinem Computer. Deine Änderungen speichert es im eigenen Ordner, damit du später weitermachen kannst. Nichts wird verschickt.

Netzwerkanfragen

Die App macht zwei Arten von Netzwerkanfragen: Sie lädt ein Sprachmodell von Hugging Face (huggingface.co), wenn du auf Download klickst, und fragt einmal am Tag bei GitHub nach der neuesten Versionsnummer, was du auf dem Startbildschirm ausschalten kannst. Keine davon enthält etwas über dich oder deine Dateien. Nach dem Laden des Modells funktioniert Captionshaper ohne Internet.

Konten, Analyse und Tracking

Gibt es nicht, weder in der App noch auf dieser Website.

Diese Website

Diese Website liegt auf GitHub Pages. GitHub kann übliche Server-Logs speichern, wie in GitHubs Datenschutzerklärung beschrieben. Die Seite setzt keine Cookies. Deine gewählte Sprache wird nur in deinem Browser gespeichert.
