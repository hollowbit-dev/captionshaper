Captionshaper herunterladen

Kostenlos, für Mac und Windows. Version 1.0.0.

Mac

Apple Silicon (M1 oder neuer), macOS 12 oder neuer

.dmg laden

Windows

Windows 10 oder 11, 64 Bit

Installer laden

Beim ersten Öffnen

Mac

  1. Öffne die .dmg und ziehe Captionshaper in Programme.
  2. Rechtsklick auf Captionshaper, Öffnen wählen, dann auf Öffnen klicken.
  3. Blockiert macOS es weiterhin, geh zu Systemeinstellungen, Datenschutz & Sicherheit, und klicke auf Trotzdem öffnen.

Windows

  1. Starte den Installer. Wenn SmartScreen erscheint, klicke auf Weitere Informationen und dann Trotzdem ausführen.
  2. Windows fragt eventuell, ob die Microsoft Visual C++ Runtime installiert werden soll. Sag ja, die Spracherkennung braucht sie.

Captionshaper ist noch nicht mit einem kostenpflichtigen Apple- oder Microsoft-Zertifikat signiert, deshalb fragen beide Systeme einmal nach.
