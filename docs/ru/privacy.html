Конфиденциальность

Captionshaper работает на вашем компьютере. Ваши видео, звук, субтитры и правки остаются там.

Приложение делает только один вид сетевых запросов: скачивает речевую модель с Hugging Face (huggingface.co), когда вы нажимаете «Скачать». Этот запрос не содержит ничего о ваших файлах.

В приложении нет аккаунтов, аналитики и слежки.

Этот сайт размещён на GitHub Pages. GitHub может хранить стандартные журналы сервера; см. его заявление о конфиденциальности. Сам сайт не использует cookies и аналитику.
