Первый запуск

Mac

  1. Откройте .dmg и перетащите Captionshaper в «Программы».
  2. Нажмите правой кнопкой на Captionshaper, выберите «Открыть», затем снова «Открыть».
  3. Если macOS всё ещё блокирует, откройте «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть».

Windows

  1. Запустите установщик. Если появится SmartScreen, нажмите «Подробнее», затем «Выполнить в любом случае».
  2. Windows может предложить установить Microsoft Visual C++ Runtime. Согласитесь: он нужен распознаванию речи.

Captionshaper пока не подписан платным сертификатом Apple или Microsoft, поэтому обе системы один раз спрашивают разрешение.
