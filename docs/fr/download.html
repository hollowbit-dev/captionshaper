Télécharger Captionshaper

Gratuit, pour Mac et Windows. Version 1.0.0.

Mac

Apple Silicon (M1 ou plus récent), macOS 12 ou ultérieur

Télécharger le .dmg

Windows

Windows 10 ou 11, 64 bits

Télécharger l'installateur

Premier lancement

Mac

  1. Ouvrez le .dmg et faites glisser Captionshaper dans Applications.
  2. Faites un clic droit sur Captionshaper, choisissez Ouvrir, puis cliquez sur Ouvrir.
  3. Si macOS le bloque encore, allez dans Réglages Système, Confidentialité et sécurité, puis cliquez sur Ouvrir quand même.

Windows

  1. Lancez l'installateur. Si SmartScreen apparaît, cliquez sur Informations complémentaires, puis Exécuter quand même.
  2. Windows peut demander d'installer le runtime Microsoft Visual C++. Acceptez : le moteur vocal en a besoin.

Captionshaper n'est pas encore signé avec un certificat payant d'Apple ou de Microsoft, donc les deux systèmes demandent une fois.
