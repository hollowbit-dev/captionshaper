Opening it the first time

Mac

  1. Open the .dmg and drag Captionshaper to Applications.
  2. Right-click Captionshaper and choose Open, then click Open.
  3. If macOS still blocks it, go to System Settings, Privacy & Security, and click Open Anyway.

Windows

  1. Run the installer. If SmartScreen appears, click More info, then Run anyway.
  2. Windows may ask to install the Microsoft Visual C++ runtime. Say yes; the speech engine needs it.

Captionshaper isn't signed with a paid Apple or Microsoft certificate yet, so both systems ask once.
