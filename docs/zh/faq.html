常见问题

真的免费吗？

是的。没有试用期、没有水印、没有限制。Captionshaper 是开源的，如果它帮你省了时间，可以在 Ko-fi 上支持。

会上传我的视频吗？

不会。一切都在你的电脑上完成。应用只会下载一次语音模型（约 570 MB），这是它唯一的联网操作。

支持哪些语言？

约 99 种，包括中文、英语、西班牙语、法语、德语、葡萄牙语、俄语和日语，并会自动识别语言。较少见的语言建议使用“最准确”模型。

准确度如何？

清晰的语音几乎每个词都对。我们用英语、西班牙语和德语的已知文稿片段测试：词错误率 0.7%，字幕与声音相差不到 0.15 秒。噪音和浓重口音会带来更多错误，所以修改也做得很快。

能翻译吗？

可以把任何支持语言的语音转成英文字幕。开始前勾选“翻译成英文”。

Windows 上速度快吗？

Windows 版使用处理器运行，在较新的电脑上约为实时的一到两倍。Apple 芯片的 Mac 使用 GPU，约为实时的五倍。

支持 Intel 芯片的 Mac 吗？

暂不支持。Mac 版需要 Apple 芯片（M1 或更新）。

可以导出哪些格式？

烧录字幕的 MP4 视频、SRT 字幕（YouTube、Premiere、DaVinci Resolve、剪映/CapCut）、网页用的 VTT、保留完整样式的 ASS，以及纯文本文字稿。

可以编辑字幕吗？

可以。点击任意字幕即可编辑，支持查找替换、拆分或合并字幕，随时撤销。不确定的词带下划线，方便先检查。

适合 TikTok、Reels 和 YouTube Shorts 吗？

适合。粗体、高亮、逐词和渐显样式专为竖屏视频设计，手机预览会显示各应用按钮的位置。

能打开哪些文件？

大多数视频和音频：MP4、MOV、MKV、WEBM、AVI、MP3、WAV、M4A 等，也包括 iPhone 视频。

视频最长多长？

没有限制。10 分钟的视频在 Apple 芯片的 Mac 上约需两分钟，更长的视频只是需要更久。

为什么第一次打开时电脑会警告？
