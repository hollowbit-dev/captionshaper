隐私

最后更新：2026 年 11 月 11 日

Captionshaper 在你的电脑上运行。你的视频、音频和字幕从不离开你的电脑。

应用如何处理你的文件

Captionshaper 读取你打开的视频或音频，识别语音并写出字幕，全部在你的电脑上完成。它会把修改保存在自己的文件夹里，方便你之后继续。不会发送任何内容。

网络请求

应用只有两种联网请求：在你点击下载时，从 Hugging Face（huggingface.co）下载语音模型；以及每天向 GitHub 询问一次最新版本号，你可以在首页关闭。两者都不包含任何关于你或你文件的信息。下载模型后，Captionshaper 无需联网即可使用。

账号、统计和追踪

应用和本网站都没有。

本网站

本网站托管在 GitHub Pages。GitHub 可能保留常规服务器日志，详见其隐私声明。网站不设置 Cookie，你选择的语言只保存在你自己的浏览器中。
