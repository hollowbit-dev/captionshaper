下载安装程序

首次打开

Mac

  1. 打开 .dmg，把 Captionshaper 拖到“应用程序”。
  2. 右键点按 Captionshaper，选择“打开”，再点“打开”。
  3. 如果 macOS 仍然阻止，前往“系统设置”→“隐私与安全性”，点“仍要打开”。

Windows

  1. 运行安装程序。如果出现 SmartScreen，点“更多信息”，再点“仍要运行”。
  2. Windows 可能会询问是否安装 Microsoft Visual C++ 运行库。请同意，语音引擎需要它。

Captionshaper 暂未使用付费的 Apple 或 Microsoft 证书签名，所以两个系统都会询问一次。

系统要求

MacApple 芯片（M1 或更新），macOS 12 Monterey 或更高
WindowsWindows 10 或 11，64 位。较新的处理器识别更快。
内存建议 8 GB 内存
磁盘空间应用约 400 MB，语音模型另需 60 MB 至 1.1 GB
