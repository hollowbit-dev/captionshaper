常见问题

真的免费吗？

是的。没有试用期、没有水印、没有限制。Captionshaper 是开源的，如果它帮你省了时间，可以在 Ko-fi 上支持。

会上传我的视频吗？

不会。一切都在你的电脑上完成。应用只会下载一次语音模型（约 570 MB），这是它唯一的联网操作。

支持哪些语言？

约 99 种，包括中文、英语、西班牙语、法语、德语、葡萄牙语、俄语和日语，并会自动识别语言。较少见的语言建议使用“最准确”模型。

准确度如何？

清晰的语音几乎每个词都对。我们用英语、西班牙语和德语的已知文稿片段测试：词错误率 0.7%，字幕与声音相差不到 0.15 秒。噪音和浓重口音会带来更多错误，所以修改也做得很快。

能翻译吗？

可以把任何支持语言的语音转成英文字幕。开始前勾选“翻译成英文”。

Windows 上速度快吗？

Windows 版使用处理器运行，在较新的电脑上约为实时的一到两倍。Apple 芯片的 Mac 使用 GPU，约为实时的五倍。

支持 Intel 芯片的 Mac 吗？

暂不支持。Mac 版需要 Apple 芯片（M1 或更新）。
